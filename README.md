# 轻爽课表

轻爽课表是一款面向班级、教师和家长的轻量级课表制作工具。无需安装软件，打开网页即可填写课程、调整作息、切换配色，并打印或保存为 PDF。

## 在线使用

官方访问地址：

<https://excelov.github.io/qingshuang-kebiao/>

项目使用 GitHub Pages 提供静态网页服务。

## 主要功能

- 课程表编辑：选择课程后点击格子即可填入，也可以清除单元格。
- 作息配置：设置上午开始时间、每节课时长、课间、午休和晚休。
- 节次数调整：分别调整上午、下午和晚上的课程节数。
- 星期范围：支持周一至周五、周一至周六和周一至周日。
- 课程颜色：每门课程可以单独设置颜色。
- 配色切换：内置多套清爽的中国古典配色方案。
- 移动端操作：手机上可以在课表、编辑面板和课程库之间切换，并通过下拉菜单快速填课。
- 打印输出：适配浏览器打印和 PDF 保存，课表底部保留版权标识。
- 本地保存：填写内容保存在当前浏览器中，刷新页面后仍可继续编辑。

## 使用方式

1. 打开在线地址，或在本地打开 `index.html`。
2. 填写班级和学期信息。
3. 设置作息时间、课程节数和显示星期。
4. 在课程库中定义课程和颜色。
5. 选择课程后点击课表格子填入。
6. 使用“打印 / 存 PDF”输出课表。

## 数据与隐私

本项目没有后端服务和账号系统，课表数据默认只保存在当前浏览器的 `localStorage` 中，不会由本项目主动上传到服务器。清除浏览器站点数据或更换浏览器，可能导致本地课表数据丢失。

## 本地预览

直接双击 `index.html` 即可预览。也可以在项目目录运行一个本地静态服务器：

```text
python -m http.server 8000
```

然后访问 <http://localhost:8000>。本地服务器不是项目运行的必需条件，只是部分浏览器调试时更方便。

## 维护说明

项目保持单文件结构，日常维护主要修改 `index.html`：

- 页面样式位于 `<style>` 标签内。
- 默认课程、默认课表和默认作息位于 JavaScript 的 `DEFAULT` 对象中。
- 配色方案位于 JavaScript 的 `SCHEMES` 对象中。
- 本地存储键名位于 `KEY` 变量中。

修改后请重点检查课程填写、清除、节次数调整、打印预览和移动端显示。
