# 轻爽课表竞品与参考调研

调研时间：2026-09-04

## 当前定位

轻爽课表当前是一个单文件、纯前端、浏览器即用的课表生成器。它的优势不在复杂排课算法，而在“打开就能做、做完能打印、样式清爽、数据保存在本地”。

## 可参考项目

### fangguan233/next_class

地址：https://github.com/fangguan233/next_class

可借鉴点：

- 文本/图片课表导入，降低手动录入成本。
- 离线模式 PWA，适合网页像 App 一样使用。
- 下一节课速览，适合移动端日常查看。
- 分享码/导入机制，适合同学、老师之间传递课表。
- 导出图片时附带二维码，利于传播。

不建议直接照搬：

- Flask 后端、AI 解析、分享码后台会显著增加维护复杂度。
- 当前项目更适合先保持静态网页，不急着上后端。

### caicaicai/miaozitie

地址：https://github.com/caicaicai/miaozitie

可借鉴点：

- 面向小学场景的工具集合定位清晰。
- 课程表生成器支持节数、星期范围和主题色配置。
- “生成后直接填写并打印”的路径很短。
- README 对每个工具的用途和使用步骤解释清楚。

适合迁移到本项目的方向：

- 增加周一到周五/周六/周日范围选择。
- 打印样式进一步优化为“家用打印友好”。
- README 增加截图或成品图。

### Qinsanlian/enrollment-timetable-comparison

地址：https://github.com/Qinsanlian/enrollment-timetable-comparison

可借鉴点：

- 强调无需安装、数据保存在本地。
- 支持撤销/重做，历史栈最多 60 步。
- 支持导出与打印，且考虑版式用途。
- 中英文界面与本地持久化做得比较完整。

适合迁移到本项目的方向：

- 增加撤销/重做。
- 增加数据导入/导出 JSON，方便换电脑或分享。
- README 明确隐私说明：课程表数据不上传。

### Pmptome/school-timetable-generator

地址：https://github.com/Pmptome/school-timetable-generator

可借鉴点：

- 项目定位简洁：专业课表快速生成。
- 提供浅色/深色截图、PWA manifest、service worker。
- 功能点包含教师分配、冲突检测、PDF/PNG/calendar 导出。

适合迁移到本项目的方向：

- 增加成品截图。
- 增加 PWA 基础能力：manifest、应用图标、离线缓存。
- 远期考虑 iCal 日历导出。

## 建议路线

### 第一阶段：视觉与体验精修

- 优化移动端：手机上改成“编辑面板 / 课表 / 课程库”分段切换。
- 课程卡片增加颜色编辑，允许用户自定义每门课颜色。
- 增加星期范围选择：周一至周五、周一至周六、周一至周日。
- 打印视图增加 A4 横向适配，减少边距浪费。
- README 增加成品截图，仓库观感更完整。

### 第二阶段：实用功能增强

- 增加撤销/重做。
- 增加导出 JSON / 导入 JSON。
- 增加导出 PNG。
- 增加一键复制分享文本。
- 增加“清空缓存 / 恢复默认 / 另存模板”。

### 第三阶段：轻量 App 化

- 增加 `manifest.json` 和 `service-worker.js`，支持 PWA 安装和离线打开。
- 增加应用图标。
- 增加版本号和缓存更新提示。

### 暂不建议

- 暂不上后端。
- 暂不接 AI 图片识别。
- 暂不做复杂自动排课算法。
- 暂不引入大型前端框架。

原因：当前产品最强价值是轻、快、可直接打印。过早复杂化会降低维护性，也会让家长和老师使用门槛变高。
