# 轻爽课表精致化路线

## 目标

保持“单文件、轻量、直接可用”的核心体验，同时把视觉完成度、打印质量、移动端体验和数据管理能力补齐。

## V1.1 建议改动

优先级最高，适合马上做：

- 增加项目截图：用于 README 成品展示。
- 打印优化：A4 横向、隐藏控制面板、课表自动居中、表格边距更稳。
- 星期范围：支持周一至周五、周一至周六、周一至周日。
- 课程颜色：每门课程允许单独换色。
- 操作反馈：填入、清除、恢复默认后给轻量提示。

## V1.2 建议改动

实用增强：

- 撤销 / 重做。
- 导出 JSON / 导入 JSON。
- 另存模板：例如“小学默认”“初中默认”“空白模板”。
- 导出 PNG：适合发微信、打印店或群聊。
- README 加维护说明和更新日志。

## V1.3 建议改动

轻量 App 化：

- 增加 PWA manifest。
- 增加 service worker 离线缓存。
- 增加应用图标。
- 增加版本号，避免用户长期吃旧缓存。

## 设计方向

- 主视觉继续保持清爽、克制、适合老师和家长。
- 不做花哨动效，重点做留白、字体层级、表格比例和打印质感。
- 按钮和控件尽量更像“工具”，减少说明文字堆叠。
- 课表主体优先保证清晰，控制面板让位于内容。

## 技术原则

- 继续保持纯前端。
- 允许从单文件逐步拆成 `index.html`、`style.css`、`script.js`，但发布体验不能变复杂。
- 不引入构建工具。
- 不引入后端。
- 所有数据默认留在浏览器本地。
